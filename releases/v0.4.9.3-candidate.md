## 中文

Companion 0.4.9.3 合并无线超时优化和 Chroma 布局修复。键盘固件与原生驱动保持 0.4.9，不需要重刷；已就绪的驱动不需要重新安装。

使用：退出旧 Companion，运行新版并启用动态照明。在 Chroma Studio 导出当前配置，点击 Companion 的“修复 Chroma 串灯”，选择导出文件并保存新副本；回到 Chroma Studio 导入、选中新副本，再设置 `】` 等冲突键的效果。

### 无线处理

- ACK 等待根据成功应答的往返时间与抖动，在 80–400 ms 内调整；不使用重发应答估算延迟。
- 连续无线无应答按 50/100/200/400/800/1000 ms 退避，保留虚拟灯光设备；不再因为无线静默超过 3 秒就删除和重建设备。恢复后发送最新颜色，不回放积压帧。
- 保留四包窗口、精确 ACK 匹配、仅补缺失包和变化灯段；丢包后降低并逐步恢复窗口。
- 有线 LampArray 出现或确认退出 2.4G 时撤下虚拟设备。真实 USB 移除、驱动错误或停止程序仍会结束连接；此更新不能证明物理接收器重置已修复。
- 原生驱动仍上报 200 ms 最小更新间隔，无线控制器可能仍按 5 fps 更新。本次优先降低额外等待和枚举抖动，不承诺与有线等速。

### Chroma 处理

提供“修复 Chroma 串灯”入口，将导出的键盘与原生/WDL 鼠标分开，按完整灯位矩阵留出间距，覆盖全部 68 灯而不只移动某个选中键。保留设备身份、灯号、按键绑定、效果参数与效果目标，生成独立配置/图层 ID；不覆盖原文件，也不直接改动运行中的 Chroma 数据库。

三个用户既有导出已重新核对：键盘图形宽 660，逻辑矩阵 28 列；40 像素灯格模型下可复现原生 P 键与 WDL 多键的重叠。修复后相关模型重叠为零，设备/效果字段保留。此前用户确认分离布局能消除旧配置串灯。40 像素模型是从导出及实测推断，未获 Razer 内部实现确认；当前 0.4.9 的 `】` 效果和新版实际导入还需实测，不能据旧导出声称已复现该键的新配置。

工具支持已观察到的 version 1、未旋转、0/40 像素灯格的 JSON 导出；不支持的格式保留原文件并报错。有线/无线切换新增设备或重新排列后，请导出当前布局再修复。原生和虚拟设备身份仍不同，Chroma 可能保留历史卡片。

验证：官方 .NET Framework 4.8 引用编译；无线超时/丢包/退避故障测试；匿名 Chroma 三设备几何及 `】`/P 目标保留检查；三个真实导出的布局与字段保持检查；安装脚本/就绪判定/包哈希检查。真实 Windows GUI、新配置导入、无线延迟和 USB 声音仍待用户验证。公开源码不含用户导出、序列号或日志。

## English

Companion 0.4.9.3 combines radio timeout improvements with Chroma layout repair. Keep the working firmware and native driver 0.4.9; no reflashing or reinstall of a ready driver is needed.

Close the old Companion and enable lighting in the new one. Export the current setup from Chroma Studio, choose **Fix Chroma coupling** in Companion, and save a new copy. Import and select that copy in Chroma Studio before testing affected keys.

ACK deadlines adapt within 80–400 ms. Sustained radio silence uses retry backoff up to 1 second and retains the virtual device instead of removing it after 3 seconds. Recovery sends the latest state. Confirmed mode changes, wired presence, physical USB removal, fatal driver errors and stopping still detach appropriately. The existing native driver retains its 200 ms minimum update interval; hardware latency is unverified.

The layout tool separates full device matrices for native and WDL mice while preserving device identities, lamp maps, bindings and effect targets. It creates new profile/layer IDs and never overwrites the input. The inferred 40-pixel model reproduces collisions in three supplied exports; repaired geometry and field preservation passed checks. Earlier separated layouts were user-confirmed effective. The latest bracket-key setup and this update's actual Chroma import still need hardware validation. Unsupported versions, rotations or cell sizes are rejected. New device instances or rearrangement may require another export/repair/import.

Software compilation, protocol fault injection, three real-export checks and package validation passed. Real Windows GUI, new-profile import, radio latency and reconnect sounds remain unverified. No private profiles or device identifiers are embedded in public source.

## 中文

0.4.9.2 仅更新 Windows 伴侣程序；继续使用现有 0.4.9/0.4.8 键盘固件及已经工作的 0.4.9 驱动，不必重刷。

- 无论 Windows 是否接管灯光，每 500 ms 检查有线 LampArray 及键盘连接模式；发现有线时撤下无线虚拟设备。
- 无线读取超时不再丢弃 pending read 或立即关闭句柄；复用未完成读取，关闭时先取消并等待。
- 短暂 ACK 丢失只重试，不立即删除/重建虚拟键盘；连续失败 3 秒才撤下设备，避免一次漏包造成 USB 提示音和枚举抖动。
- 采用最多 4 包在途、精确 ACK 对应和仅重发缺失包。单键/局部变化仅发送有变化的灯段，全帧最多 8 包。
- 桥接发送周期从 200 ms 缩短到 125 ms；原驱动上报的 200 ms 最小更新间隔保持不变，所以系统控制器仍可能按 5 fps 更新。实际无线延迟需实测，不能宣称与有线等速。
- 继续提供中英切换、仓库链接、日志/源码/固件导出。

用户反馈：重置 Windows 背景光控制后，有线与 2.4G 均能通过 Chroma 同步。这证明 0.4.9 桥接链路至少已在该设备组合中工作，不代表所有效果/休眠/主机回归通过。

`】` 与鼠标共同高亮尚未修复。该键元数据为 LED 38、HID 0x30；截图中 Chroma 画布本身也共同选中鼠标，支持布局/选区碰撞的判断，但当前配置的具体碰撞坐标仍未验证。按 M 将原生与 WDL 鼠标移出键盘逻辑灯位范围可作对照；需要最新 .ChromaEffects 导出进一步修正。

有线和虚拟无线具有不同设备身份，应用可能保留历史卡片。本版修正的是同时活动与反复枚举，不修改 Chroma 保存的设备历史或强行合并身份。

此更新已进行编译、故障注入和打包校验；真实 Windows 的延迟、USB 提示音及切换行为仍待验证。

## English

Companion 0.4.9.2 updates the Windows worker/UI only. Keep firmware 0.4.8/0.4.9 and the working 0.4.9 driver; no reflashing is required.

Mode/wired-presence checks run every 500 ms regardless of RGB ownership. Soft read deadlines retain the owned pending read. Lost ACKs retry without immediately removing the virtual device; sustained failure has a 3-second grace period. Up to four exact-matched packets are in flight; only missing ACKs and changed LED spans are resent. The worker scheduling interval is 125 ms; the unchanged driver still advertises a 200 ms minimum, so system effects may remain capped at 5 fps. Actual latency requires hardware testing.

The user reports successful Chroma output in both modes after resetting background lighting control. The right-bracket/mouse joint highlight is still unresolved; the screenshot shows it in Chroma's own selection canvas. The key is LED 38 / HID 0x30. A current .ChromaEffects export is needed to establish the exact layout collision.

Wired and virtual wireless devices retain distinct identities. Applications may cache historical cards. This update targets simultaneous activation and enumeration churn, not application history removal. Software tests passed; real Windows latency, reconnect sound and mode switching remain unverified for this update.

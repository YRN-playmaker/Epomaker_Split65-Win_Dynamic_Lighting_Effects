## English

Experimental 0.4.9 candidate: wired LampArray firmware and a Windows 2.4G software bridge.

Repository: https://github.com/YRN-playmaker/Epomaker_Split65-Win_Dynamic_Lighting_Effects

- One Companion EXE with live 中文 / English selection and a repository link.
- Embedded install/repair/uninstall, logs, complete source and firmware export. No separate CMD/INF/DLL steps.
- Supports keyboard firmware 0.4.8 / 0.4.9 over the existing receiver. Receiver reflashing is not required. Keep the Companion running. First setup needs administrator access and a locally generated signing certificate.
- Firmware 0.4.9 restores wired PID E4C6 for Hub and includes the slave-key wake change. This language update does not change the original 0.4.9 BIN, native driver or worker.
- The driver opens VHF during PrepareHardware, with ordered teardown and startup-stage diagnostics.

**Real Windows driver loading, wireless LampArray enumeration/output, Hub mapping and prolonged input/sleep behavior remain unverified. This is not a stable or certified release.**

Run the EXE from the Companion ZIP. Use Source ZIP and Firmware to export corresponding files. Flashing the BIN alone does not add LampArray to the stock receiver. Use Logs ZIP if setup fails.

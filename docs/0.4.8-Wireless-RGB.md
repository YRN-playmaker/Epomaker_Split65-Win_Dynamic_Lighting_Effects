# 0.4.8：2.4G Raw RGB 候选

日期：2026-10-18。当前版已经构建并通过软件回归，尚无 Windows/键盘实机确认。不要把无线逐灯串流等同于接收器已经支持原生 Windows 动态照明。

## 改动

- 通过已有 32 字节 Raw HID / VIA 无线通道接收 RGB：0x24 每包至多 9 灯，68 灯完整帧至少 8 包。
- 无线自定义命令回复经 replaced_hid_send / md_send_raw 返回接收器，不再错误走键盘 USB。
- 有线 LampArray 只在有线模式接管；2.4G Raw RGB 独立接管，不依赖键盘 USB_ACTIVE。
- 无线数据或 0x25 每次续期，3 秒无更新释放。断连或切换模式也释放；重新连接本身不重放旧颜色。
- 无关 USB 重置不取消有效无线串流。有线静态灯光保持原来的无续期行为。
- 保留 0x44 分体包和 v0.4.7 描述符、灯号、按键绑定、PID。固件修订及 bcdDevice 更新为 0x48 / 0048。
- 仅开放 USB / 2.4G，蓝牙串流拒绝；输入与休眠代码保留。

## 安装与验证

当前用户双侧 v0.4.7：先只将左侧刷成 split65-dynamic-lighting-v0.4.8.bin，右侧保留 v0.4.7 即可。两侧共用同一 BIN，但本轮无需重复刷右侧。刷写方法见 FLASHING.md。

完全退出 OpenRGB 与 Hub。键盘切到 2.4G，移除直连电脑的数据线，保留接收器及正常左右连接。使用 Edge/Chrome 打开 tools/wireless-rgb/Start-Wireless-RGB.html，选择接收器，然后依次设置全红、全绿、全蓝，观察两侧；可用灯号 40 测试 P 键。

连接阶段仅查询 0x30；只有识别 DL2、修订 0x48、68 灯及协议能力才开放写颜色。测试页使用 80 ms 包间隔和逐包回复确认，每秒续期；完成后点击恢复内置灯效。关闭或后台节流可能触发 3 秒租期释放，这不是键盘输入休眠错误。

页面能证明的范围是命令应答与颜色观察；它不创建 Windows LampArray。无线 Windows 动态照明还需要复用该通道的虚拟设备桥接，或扩展接收器自身接口。此包未实现上述桥接，不含驱动安装器。

## 保留与回退

firmware/split65-dynamic-lighting-v0.4.7.bin 为原已交付镜像，未改动。若候选版影响输入或现有有线动态照明，只将本轮升级的左侧退回 0.4.7，右侧保持即可。input-check 文件仅供开发隔离，不是推荐安装版本。

# 0.4.9 候选版

该版本的无线 Windows 动态照明由 Windows 伴侣程序和虚拟 HID 驱动提供。单刷 BIN 不会改变原厂接收器的 USB 描述符，也不会自动获得无线动态照明。

## 刷写选择

- 只验证软件桥接：左侧当前 0.4.8 可保持，先运行新版伴侣程序。
- 修复有线 Hub 设备匹配：把左侧刷为 0.4.9；PID 从 E4C7 恢复 E4C6，bcdDevice=0049，无 USB 全零序列号。
- 验证此次仓库已有的右侧按键唤醒修改：把右侧刷为同一个 0.4.9 BIN。该修改仍需实机验证。
- 左右使用同一个 WB32FQ95 BIN，由硬件引脚区分半区。程序只导出文件，不刷写。保留之前可用的 BIN 供回退。

## Hub 问题的证据

2026-10-18 获取 https://hub.epomaker.com/key-mapping 的脚本 index-ACf8N4CE.js，Split65 注册项为 vendorId 13357、productId 58566，即 342D:E4C6，设备授权按配置中的 VID/PID 过滤。0.4.8 的有线 E4C7 不匹配。恢复 PID 解决该已确认匹配差异；完整连接、读取和写入仍需用户在 Hub 上验证。

## 动态照明验证

退出 OpenRGB、Hub、VIA 和测试网页。切到 2.4G，启动 Companion → 启用动态照明，允许首次安装的 UAC。接收器握手后应创建独立虚拟 LampArray。随后检查 Windows 动态照明设备列表，再测试系统纯色。出现错误时用同一窗口“导出日志”。

本版不添加键盘/鼠标输入接口，不替换物理设备驱动。输入仍由原厂接收器提供。该设计不能代替长期输入、休眠、重连和并发测试。

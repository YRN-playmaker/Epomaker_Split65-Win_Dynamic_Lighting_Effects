EPOMAKER SPLIT65 · v0.4.8 候选版

验证 2.4G 逐灯控制

本页通过接收器直接控制灯光。它用于测试无线颜色传输，尚不提供 Windows 动态照明自动识别。

保留整个文件夹，用 Edge 或 Chrome 打开本页。退出 OpenRGB 和 Hub；键盘切到 2.4G，拔掉键盘直连电脑的数据线，保留接收器及正常的左右连接。

1 · 连接

选择 Split65 接收器。连接时只读取固件信息，确认 0.4.8 后才开放颜色按钮。

尚未连接
2 · 观察两侧灯光

先依次尝试红、绿、蓝，再测试单个灯位。颜色会经过键盘的亮度上限。

40 对应出厂布局 P 键

本页用低速、逐包确认方式发送完整 68 灯帧。保持页面打开以续期；停止续期后无线控制在约 3 秒内释放。浏览器后台节流也可能触发释放。

结果
等待操作。

页面不修改按键、驱动或 EEPROM，不会刷机。完成后点击“恢复键盘内置灯效”。若操作报错，停止续期后等待约 3 秒恢复；原有有线 Windows 动态照明继续保留。

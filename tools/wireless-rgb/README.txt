Split65 0.4.8 候选：2.4G Raw RGB 测试

保留整个文件夹，用 Edge 或 Chrome 打开 Start-Wireless-RGB.html。
本页直接通过接收器控制灯光，不创建 Windows 动态照明设备。

当前双侧 0.4.7 的用户，本轮只刷左侧 0.4.8，右侧保留 0.4.7。
退出 OpenRGB、Hub 等灯控器，切到 2.4G，断开键盘直连电脑的数据线，
保留接收器和正常左右连接。选择接收器后确认页面显示 0.4.8、2.4G。
依次全红、全绿、全蓝，观察两侧；灯号 40 对应出厂布局 P。
完成后点“恢复键盘内置灯效”。停止续期约 3 秒自动释放无线控制。

本版软件检查通过，硬件尚待确认。Windows 无线自动识别尚需桥接，
不要将测试页可改灯当成原生 LampArray 已实现。

无驱动安装，不修改按键或 EEPROM，不自动刷机。
源码与检查见仓库 docs/0.4.8-Wireless-RGB.md。

只读状态探测（可选，命令行）：
  python probe_status.py
只发送 0x30 查询并解析 32 字节回复，不写颜色、不写 EEPROM。
用于确认固件修订 0x48、设备为 2.4G、灯数 68、Raw 协议可用。
